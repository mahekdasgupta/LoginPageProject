# Login Page Project

A beginner-friendly HTML/CSS/JavaScript login page for a Git and GitHub practical.

## Run
Open `index.html` in a browser. The form performs local demo validation only; it does not authenticate users or connect to a backend.

## Git practical
The repository history demonstrates separate commits for the initial page, logo, heading, styling, and form validation on a feature branch, followed by merging into `main`.

## Note
Use only fictional credentials. This project is for learning and is not production authentication.
